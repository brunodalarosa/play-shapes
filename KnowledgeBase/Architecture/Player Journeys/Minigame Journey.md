Every minigame player journey consist of three 3 chapters:
1. [[Pre-minigame Screen]]
2. Minigame gameplay
3. Results screen

The Pre-minigame screen is mandatory in every normal launch, including minigames with
readiness checks inside gameplay. Debug flows are exceptions. No skip setting exists.
See [[Journey Change Rules|player journey implementation guidance]].
