# Workshop fonts

The workshop window's type, from https://github.com/google/fonts at commit `1c627bfa`:

- `Roboto.ttf` is `ofl/roboto/Roboto[wdth,wght].ttf`, the Material Design 3 typeface.
- `RobotoMono.ttf` is `ofl/robotomono/RobotoMono[wght].ttf`, for numbers and readouts.

Both are variable fonts under the SIL Open Font License 1.1 ([OFL.txt](OFL.txt)); Roboto
Mono's copyright line is "Copyright 2015 The Roboto Mono Project Authors". They are left out of
the exported game with the rest of `workshop/`.
