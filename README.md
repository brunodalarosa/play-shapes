# play-shapes
Play shapes is a local network multiplayer party game

## Run the phase 1 lobby

Open `project.godot` in Godot 4.7.2 and press F5. Connect your phone to the same
network and scan the lobby QR code to open Hello world. Select the correct LAN
address if the PC has multiple adapters. The game serves all browser files itself.

See [DEVELOPMENT.md](DEVELOPMENT.md) for architecture, web build commands, tests,
network troubleshooting, and remaining phone/export checks.
