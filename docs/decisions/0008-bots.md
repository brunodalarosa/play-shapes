# 0008. Bots that fill a game are wanted

Decided by the project owners on 2026-10-03.

## Situation

The debug menu was built to create no simulated player, to keep the first version simple. Testing with several players needs several phones, and a real game may want seats filled.

## Decision

Bots that play as players are wanted, both to fill a game and to test it. The earlier rule against simulated players no longer holds where they help.

Bots are their own task. They are not a side effect of test tooling.

## What follows

- Bots that fill a real game run inside the host, because players do not run anything but a browser.
- They feed the same input path the phones use, so they fit after the input pipeline is reworked.
