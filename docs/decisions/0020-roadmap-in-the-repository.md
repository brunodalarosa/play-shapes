# 0020. The plan lives in the repository

Decided by the project owners on 2026-10-03.

## Situation

What was done, what comes next and which bugs are known existed only in one contributor's notes. The repository's issue tracker is turned off, and agents cannot see a planning system outside the repository.

## Decision

`docs/roadmap.md` holds what is done, what is next, the backlog and the known bugs, without ticket numbers. The owners decide its content.

## What follows

- A task is described in a sentence, in the roadmap or by an owner. Pull requests state the task the same way and carry no task number.
- A change that finishes or adds work updates the roadmap.
